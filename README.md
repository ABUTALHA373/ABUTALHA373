## 👨‍💻 About Me

I'm a web developer primarily focused on **Laravel and PHP**, with an interest in building reliable, maintainable, and scalable web applications.

I enjoy working on the parts of an application that make everything work together — from database design and backend logic to APIs, authentication, application architecture, and deployment.

For the application interface, I mainly work with **Laravel Blade and Livewire**, rather than focusing on frontend frameworks.

I'm continuously improving my development practices and exploring better ways to design, build, deploy, and maintain software.

---

## 🚀 What I Do

* **Laravel Development** — Building maintainable and scalable web applications with Laravel, PHP, Blade, and Livewire
* **Backend & API Development** — Developing RESTful APIs, authentication, authorization, business logic, integrations, and application services
* **Database Development** — Designing relational databases, relationships, queries, data models, and application data structures
* **Server-Side UI Development** — Building interactive interfaces with Laravel Blade and Livewire
* **Application Architecture** — Structuring applications with clean, organized, and maintainable code
* **Third-Party Integrations** — Working with APIs, libraries, services, and plugins to extend application functionality
* **Deployment & Infrastructure** — Working with Linux servers, Apache, DNS, SSL, Cloudflare, databases, and deployment workflows
